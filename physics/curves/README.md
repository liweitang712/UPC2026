# Measured drag references for M3

`goff2026_trionda_b` and `goff2026_jabulani_b` are digitized wind-tunnel mean drag curves for fixed, nonspinning orientation B. The label B is specific to each ball. Goff et al. measured the Trionda data and reproduced the Jabulani measurements from their reference 8. Each JSON records the figure, pixel picks and calibrations, curve knots, approximate transition band, source domain and measurement conditions. [Goff et al., 2026, Figure 7](https://doi.org/10.3390/app16062808) · [Predecessor measurements](https://doi.org/10.1177/17543371221140497)

Figure 7 plots speed. The Reynolds knots use the diameter and reference kinematic viscosity reported in §2.1, 0.22 m and 1.55 × 10⁻⁵ m²/s. The critical Reynolds values printed in Table 1 differ from this conversion and are preserved separately in the metadata. The transition bands are approximate readings from the end of the low-speed plateau to the drag minimum. The digitization tolerances describe picking error and exclude instrument and shot-to-shot variability.

Pass a registered ID in `curve`, a positive `cd_anchor`, and a fixed `reference_speed_m_s` to M3. The piecewise-linear curve is shifted to match the anchor at that speed. Choose the same reference speed for comparisons across curves. By default, positive relative speeds outside the tabulated Reynolds interval fail explicitly. `curve_policy="clamp"` holds the nearest endpoint and returns a domain flag. With the nominal case constants and viscosity of 1.81 × 10⁻⁵ Pa s, the common upper bound corresponds to 33.3 m/s. Record any weight outside the measured domain when using clamping. At zero relative speed, aerodynamic force vanishes.
